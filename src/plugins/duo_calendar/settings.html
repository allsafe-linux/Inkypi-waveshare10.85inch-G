日期留空则默认为今天。
分栏 = 左边万年历 + 右边待办；全屏 = 整屏万年历，格子更宽。
从播放列表里的 待办清单 插件读取第 N 条清单，显示在右侧栏。 填 0 = 不关联。要把待办清单加进播放列表并保存，服务器才读得到。
每行一条，[ ] 未完成、[x] 已完成（会打勾并划掉）。
留空 = 白底。四色屏只有黑白红黄，照片会被抖成点阵，所以默认只取很淡的一层。 拉取失败会自动退回白底，不影响日历。
正文色画日期数字和农历小字（建议黑）；强调色画月份名、节日、节气（建议红）； 黑底色块字色画「今天」标记和待办标题条（建议黄）。
与白底同色的选项会自动改用黑色（标题消失就是这么来的）；与黑底同色的会改用黄色。
